TL;DR — PM TakeawayAgentic products can be shipped fast when you use composable tools and clear decision trees. The key insight: break complex workflows (risk scoring → approval logic → notification) into discrete agent steps rather than monolithic AI calls. This architectural thinking applies to any PM designing agent-first features.
Read more

Lenny built "Merge Mommy," a PR review bot that uses Vercel Eve agents and Codex to automate part of code review. The bot scores PR risk, auto-approves low-risk changes, and escalates ambiguous cases to Slack for human review. The full workflow—from setup to deployment—took 30 minutes.

Key technical patterns for PMs: agents excel at sequential decision-making (does this pass linter? → is it high-risk? → notify owner). The speed-to-ship demonstrates why agent frameworks matter: they let you orchestrate AI calls, human handoff, and tool invocation without building orchestration from scratch.

TL;DR — PM TakeawaySecurity vulnerabilities in data-driven products often hide in permission boundaries. Read more

Datasette released critical SQL injection fixes affecting instances that serve both public and private tables in the same database with permission controls. The vulnerability allowed users with execute-sql permission to potentially access restricted data. Both the 1.0 alpha branch and the stable 0.65 line received patches.

For product teams: this pattern—mixing data access levels, custom permission logic, and query execution—is increasingly common in AI-powered data products. Whether you're building internal analytics dashboards or data exploration features, prioritize security audits at the permission boundary, especially when agents or users can execute custom queries.

Read more

SVPG observes the core tension: AI tools let engineers write more code, but more code ≠ better products. The paradox appears across the industry—acknowledged by McKinsey and others. Teams are moving fast but in unmeasured directions.

The implication for PMs: AI amplifies bad prioritization. If your discovery is weak, you'll ship more garbage faster. If your metrics are vanity metrics, you'll hit them harder. The fix isn't better AI tools—it's better PM discipline: clearer OKRs, faster learning loops, and willingness to kill features that don't move the needle.
